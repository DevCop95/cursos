Web Hacking y Bug Bounty: OWASP Top 10 con ética

Aprende a encontrar y reportar los fallos más comunes de las aplicaciones web (control de acceso roto, inyección SQL, XSS, SSRF y autenticación débil) siguiendo el OWASP Top 10, con la línea ética de un programa de bug bounty real: alcance, reglas que nunca se rompen y divulgación responsable. Practicas con curl contra la API de una tienda ficticia en una terminal simulada en el navegador.

3 semanas · 16 lecciones · 7 laboratorios · en español
