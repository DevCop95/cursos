# Dev101x

Plataforma de cursos de ciberseguridad con laboratorios prácticos en el navegador.

🌐 **https://cursos.dev101x.online**

## Desarrollo local

```bash
npm install          # herramientas de desarrollo (Tailwind CLI)
npm run build:css    # genera css/tailwind.css
npm run dev          # http://localhost:3000
npm test             # tests unitarios
```

## Uso responsable

Las técnicas que se enseñan en los cursos solo deben aplicarse sobre sistemas propios
o con autorización expresa.
