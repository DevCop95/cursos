Búsqueda avanzada y exposición pública: Google y GitHub

Aprende a usar operadores de Google y GitHub Code Search para revisar exposición pública en un entorno autorizado. Practica con un simulador y datos completamente ficticios; no consulta Internet ni muestra credenciales reales.

1 semana · 7 lecciones · 3 laboratorios · en español
